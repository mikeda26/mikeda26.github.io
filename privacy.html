Privacy Policy

Email Digest Agent is a personal tool used only by its owner. It requests read-only access to the owner's Gmail to identify threads awaiting a reply.

Email content is processed in memory to build a daily summary and is not stored, sold, or shared, except for processing by the Anthropic Claude API to classify messages.

Use of Google user data complies with the Google API Services User Data Policy, including the Limited Use requirements.
